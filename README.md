# Four-Bar Mechanism

## Project Overview
This repository contains the mechanical design, 2D drafting, and kinematic simulation of a classic four-bar mechanism. The project models the fundamental mechanical conversion of continuous rotational motion into oscillating motion using four rigid links: a fixed frame, a driving crank, a connecting coupler, and an oscillating rocker. 

## Mechanism Specifications
The mechanism was designed and simulated with the following dimensional parameters:
* **Crank Length (Blue Link):** 216 mm
* **Coupler Length (Green Link):** 831 mm
* **Rocker Length (Red Link):** 581 mm
* **Frame Length (Base distance):** 485 mm
* **Rod Breadth/Thickness:** 10 mm
* **Pin / Pivot Hole Diameter:** 10 mm ($\phi 10$)

## Software Used
* **PTC Creo Parametric:** Utilized for part modeling and kinematic position analysis.
